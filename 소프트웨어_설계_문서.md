## 4. 소프트웨어 Top-level 구조

### 4.1 시스템 아키텍처 개요

VitaSense는 **3계층 아키텍처(Three-Tier Architecture)**를 기반으로 설계되었습니다.

```
┌─────────────────────────────────────────────────────────────┐
│                    프레젠테이션 계층                           │
│         (Web Frontend - React/Vue + HTML Test Page)          │
└────────────────────────┬────────────────────────────────────┘
                         │ HTTP/HTTPS
                         │ REST API
┌────────────────────────▼────────────────────────────────────┐
│                    애플리케이션 계층                           │
│                  (Node.js + Express.js)                      │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐      │
│  │ 인증 모듈     │  │ PDF 분석     │  │ 알람 스케줄러 │      │
│  │ (Kakao OAuth)│  │ 모듈         │  │ (node-cron)  │      │
│  └──────────────┘  └──────────────┘  └──────────────┘      │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐      │
│  │ 영양제 추천   │  │ 건강 기록    │  │ 알림 서비스   │      │
│  │ 서비스       │  │ 관리         │  │ (KakaoTalk)  │      │
│  └──────────────┘  └──────────────┘  └──────────────┘      │
└────────────────────────┬────────────────────────────────────┘
                         │ SQL
                         │ MySQL Protocol
┌────────────────────────▼────────────────────────────────────┐
│                      데이터 계층                              │
│  ┌──────────────────────┐  ┌──────────────────────┐         │
│  │ user_info Database   │  │ vitasense Database   │         │
│  │ (사용자 인증 정보)      │  │ (영양제, 알람 정보)    │         │
│  └──────────────────────┘  └──────────────────────┘         │
│                    MySQL 8.0 (RDS)                           │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                    외부 서비스 연동                            │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐      │
│  │ Kakao OAuth  │  │ KakaoTalk    │  │ Python PDF   │      │
│  │ 2.0 API      │  │ Message API  │  │ Extractor    │      │
│  └──────────────┘  └──────────────┘  └──────────────┘      │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 주요 구성 요소

#### 4.2.1 백엔드 서버 (Node.js + Express.js)
- **역할**: 모든 비즈니스 로직 처리 및 API 제공
- **기술 스택**: Node.js 18.x, Express.js 4.x
- **포트**: 4000 (기본값)

#### 4.2.2 데이터베이스 (MySQL 8.0)
- **구조**: 이중 데이터베이스 아키텍처
  - `user_info`: 사용자 인증 및 건강 기록
  - `vitasense`: 영양제, 알람, 추천 정보
- **연결**: Connection Pool 방식

#### 4.2.3 Python PDF 분석 엔진
- **역할**: PDF 문서에서 건강 지표 추출
- **기술**: PyMuPDF, EasyOCR
- **통신**: Node.js에서 child_process로 실행

#### 4.2.4 외부 API 연동
- **Kakao OAuth 2.0**: 사용자 인증
- **KakaoTalk Messaging API**: 알림 전송

### 4.4 데이터 흐름도

#### 4.4.1 사용자 인증 흐름

```
사용자 → GET / → Kakao Login URL 반환
         ↓
사용자 → Kakao 로그인 페이지
         ↓
Kakao → Redirect with code → /kakao/callback
         ↓
authController → Kakao Token Exchange
         ↓
authController → DB에 사용자 정보 저장 (user_info.users)
         ↓
authController → JWT 토큰 발급 → httpOnly Cookie 설정
         ↓
사용자 → 로그인 완료
```

#### 4.4.2 PDF 분석 흐름

```
사용자 → POST /pdf/upload (PDF 파일)
         ↓
pdfIO.getResults → Python getResults.py 실행
         ↓
PDF_TEXT.py 또는 PDF_ocr.py → 건강 지표 추출
         ↓
pdfIO → Node.js에 JSON 반환
         ↓
pdfIO.getJudges → Python getJudge.py 실행
         ↓
건강 상태 판정 (정상/주의/위험)
         ↓
supplementService → 건강 상태 기반 영양제 추천
         ↓
사용자 → 분석 결과 + 추천 영양제 반환
```

#### 4.4.3 알람 흐름

```
사용자 → POST /alarms/setup (영양제 선택)
         ↓
alarmScheduler.setupUserAlarms
         ↓
DB에 user_choices 생성 (vitasense.user_choices)
         ↓
alarmScheduler.generateAlarmTimes
         ↓
식전/식후/상관없음 기반 시간 계산
         ↓
DB에 user_alarms 생성 (vitasense.user_alarms)
         ↓
매일 00:00 (Cron) → 새로운 알람 생성
         ↓
매분 (Cron) → 현재 시간 알람 확인
         ↓
notificationService.sendKakaoTalk
         ↓
KakaoTalk API → 사용자에게 알림 전송
```

### 6.2 각 Class들의 설계

#### 6.2.1 AuthController (authController.js)

**역할**: 인증 관련 HTTP 요청을 처리하는 컨트롤러

##### 멤버 Data 설명

| 변수명 | 타입 | 설명 |
|-------|------|------|
| `db` | Connection Pool | user_info 데이터베이스 연결 풀 |
| `jwt` | Library | JSON Web Token 라이브러리 |
| `kakaoAuthService` | Module | Kakao 인증 서비스 모듈 |
| `JWT_SECRET` | String | JWT 토큰 암호화 비밀 키 (환경변수) |
| `CLIENT_URL` | String | 프론트엔드 URL (환경변수) |

##### 멤버 함수 설명

**1. `kakaoCallback(req, res)`**

- **설명**: Kakao OAuth 콜백을 처리하여 사용자를 인증하고 JWT 토큰을 발급
- **매개변수**:
  - `req`: Express Request 객체 (code 포함)
  - `res`: Express Response 객체
- **반환값**: HTTP Response (Redirect 또는 JSON)
- **처리 흐름**:
  1. URL에서 `code` 파라미터 추출
  2. `kakaoAuthService.getKakaoToken(code)`로 액세스 토큰 받기
  3. `kakaoAuthService.getKakaoUserInfo(accessToken)`로 사용자 정보 받기
  4. 데이터베이스에서 사용자 조회 (`SELECT * FROM users WHERE kakao_id = ?`)
  5. 없으면 새 사용자 생성 (`INSERT INTO users`)
  6. JWT 토큰 발급 (`jwt.sign()`)
  7. httpOnly 쿠키에 토큰 저장
  8. 프론트엔드로 리다이렉트 (`CLIENT_URL/home`)

**예시 코드**:
```javascript
exports.kakaoCallback = async (req, res) => {
  try {
    const { code } = req.query;

    // 1. Kakao 액세스 토큰 받기
    const tokenData = await kakaoAuthService.getKakaoToken(code);
    const { access_token, refresh_token } = tokenData;

    // 2. Kakao 사용자 정보 받기
    const userInfo = await kakaoAuthService.getKakaoUserInfo(access_token);
    const { id: kakaoId, properties } = userInfo;

    // 3. DB에서 사용자 조회
    const [users] = await db.query(
      'SELECT * FROM users WHERE kakao_id = ?',
      [kakaoId]
    );

    let userId;
    if (users.length === 0) {
      // 4. 새 사용자 생성
      const [result] = await db.query(
        `INSERT INTO users (kakao_id, nickname, kakao_access_token, kakao_refresh_token)
         VALUES (?, ?, ?, ?)`,
        [kakaoId, properties.nickname, access_token, refresh_token]
      );
      userId = result.insertId;
    } else {
      userId = users[0].id;
      // 토큰 업데이트
      await db.query(
        `UPDATE users SET kakao_access_token = ?, kakao_refresh_token = ?
         WHERE id = ?`,
        [access_token, refresh_token, userId]
      );
    }

    // 5. JWT 토큰 발급
    const token = jwt.sign(
      { user_id: userId, username: properties.nickname },
      process.env.JWT_SECRET,
      { expiresIn: '1h' }
    );

    // 6. 쿠키에 토큰 저장
    res.cookie('token', token, {
      httpOnly: true,
      secure: process.env.NODE_ENV === 'production',
      maxAge: 3600000 // 1시간
    });

    // 7. 프론트엔드로 리다이렉트
    res.redirect(`${process.env.CLIENT_URL}/home`);

  } catch (error) {
    console.error('카카오 로그인 처리 중 에러 발생 :', error);
    res.status(500).json({ message: '로그인 처리에 실패했습니다.' });
  }
};
```

#### 6.2.2 AuthMiddleware (authMiddleware.js)

**역할**: 요청에서 JWT 토큰을 검증하여 인증 상태를 확인

##### 멤버 Data 설명

| 변수명 | 타입 | 설명 |
|-------|------|------|
| `jwt` | Library | JSON Web Token 라이브러리 |
| `JWT_SECRET` | String | JWT 토큰 검증용 비밀 키 (환경변수) |
| `ERROR_CODES` | Object | 에러 코드 정의 (errors.js) |

##### 멤버 함수 설명

**1. `authenticateToken(req, res, next)`**

- **설명**: JWT 토큰을 검증하여 사용자 인증 상태를 확인하는 미들웨어
- **매개변수**:
  - `req`: Express Request 객체
  - `res`: Express Response 객체
  - `next`: 다음 미들웨어로 전달하는 함수
- **반환값**: 없음 (next() 호출 또는 에러 응답)
- **처리 흐름**:
  1. 쿠키 또는 Authorization 헤더에서 토큰 추출
  2. 토큰이 없으면 에러 응답 (401)
  3. `jwt.verify()`로 토큰 검증
  4. 검증 성공 시 `req.user`에 사용자 정보 저장
  5. `next()` 호출하여 다음 미들웨어로 전달

**예시 코드**:
```javascript
const jwt = require('jsonwebtoken');
const ERROR_CODES = require('../errors');

exports.authenticateToken = (req, res, next) => {
  // 1. 쿠키 또는 헤더에서 토큰 추출
  const token = req.cookies.token ||
                (req.headers.authorization &&
                 req.headers.authorization.split(' ')[1]);

  // 2. 토큰이 없으면 에러
  if (!token) {
    return res.status(401).json({
      code: ERROR_CODES.TOKEN_MISSING,
      message: '토큰이 없습니다.'
    });
  }

  // 3. 토큰 검증
  jwt.verify(token, process.env.JWT_SECRET, (err, user) => {
    if (err) {
      // 토큰 만료 또는 유효하지 않음
      return res.status(403).json({
        code: ERROR_CODES.TOKEN_INVALID,
        message: '토큰이 유효하지 않습니다.'
      });
    }

    // 4. 사용자 정보 저장
    req.user = user;  // { user_id, username }

    // 5. 다음 미들웨어로 전달
    next();
  });
};
```

#### 6.2.3 KakaoAuthService (kakaoAuthService.js)

**역할**: Kakao API와 통신하여 OAuth 인증 처리

##### 멤버 Data 설명

| 변수명 | 타입 | 설명 |
|-------|------|------|
| `axios` | Library | HTTP 클라이언트 라이브러리 |
| `KAKAO_REST_API_KEY` | String | Kakao REST API 키 (환경변수) |
| `KAKAO_REDIRECT_URI` | String | Kakao 리다이렉트 URI (환경변수) |
| `KAKAO_CLIENT_SECRET` | String | Kakao Client Secret (환경변수) |
| `KAKAO_AUTH_URL` | String | Kakao 인증 서버 URL |
| `KAKAO_API_URL` | String | Kakao API 서버 URL |

##### 멤버 함수 설명

**1. `getKakaoLoginURL()`**

- **설명**: Kakao 로그인 URL을 생성하여 반환
- **매개변수**: 없음
- **반환값**: String (Kakao 로그인 URL)
- **처리 흐름**:
  1. Kakao OAuth 파라미터 생성 (response_type, client_id, redirect_uri, scope)
  2. URL 조합하여 반환

**예시 코드**:
```javascript
exports.getKakaoLoginURL = () => {
  const params = new URLSearchParams({
    response_type: 'code',
    client_id: process.env.KAKAO_REST_API_KEY,
    redirect_uri: process.env.KAKAO_REDIRECT_URI,
    scope: 'talk_message,profile_nickname'
  });

  return `https://kauth.kakao.com/oauth/authorize?${params.toString()}`;
};
```

**2. `getKakaoToken(code)`**

- **설명**: Authorization code를 사용하여 Kakao 액세스 토큰을 받음
- **매개변수**:
  - `code`: String (Kakao로부터 받은 authorization code)
- **반환값**: Object `{ access_token, refresh_token, expires_in }`
- **처리 흐름**:
  1. Kakao 토큰 엔드포인트에 POST 요청
  2. 응답에서 액세스 토큰 및 리프레시 토큰 추출
  3. 반환

**예시 코드**:
```javascript
exports.getKakaoToken = async (code) => {
  const params = new URLSearchParams({
    grant_type: 'authorization_code',
    client_id: process.env.KAKAO_REST_API_KEY,
    redirect_uri: process.env.KAKAO_REDIRECT_URI,
    code: code,
    client_secret: process.env.KAKAO_CLIENT_SECRET
  });

  const response = await axios.post(
    'https://kauth.kakao.com/oauth/token',
    params.toString(),
    {
      headers: {
        'Content-Type': 'application/x-www-form-urlencoded'
      }
    }
  );

  return response.data;  // { access_token, refresh_token, ... }
};
```

**3. `getKakaoUserInfo(accessToken)`**

- **설명**: 액세스 토큰을 사용하여 Kakao 사용자 정보를 조회
- **매개변수**:
  - `accessToken`: String (Kakao 액세스 토큰)
- **반환값**: Object `{ id, properties: { nickname } }`
- **처리 흐름**:
  1. Kakao API에 GET 요청 (Authorization 헤더 포함)
  2. 사용자 정보 반환

**예시 코드**:
```javascript
exports.getKakaoUserInfo = async (accessToken) => {
  const response = await axios.get('https://kapi.kakao.com/v2/user/me', {
    headers: {
      Authorization: `Bearer ${accessToken}`
    }
  });

  return response.data;  // { id, properties: { nickname }, ... }
};
```

#### 6.2.4 Database Pool (db.js)

**역할**: MySQL 데이터베이스 연결 풀 관리

##### 멤버 Data 설명

| 변수명 | 타입 | 설명 |
|-------|------|------|
| `mysql` | Library | mysql2/promise 라이브러리 |
| `pool` | Connection Pool | MySQL 연결 풀 객체 |
| `DB_HOST` | String | 데이터베이스 호스트 (환경변수) |
| `DB_USER` | String | 데이터베이스 사용자 (환경변수) |
| `DB_PASSWORD` | String | 데이터베이스 비밀번호 (환경변수) |
| `DB_NAME` | String | 데이터베이스 이름 (환경변수) |

##### 멤버 함수 설명

**1. `createPool(config)`**

- **설명**: MySQL 연결 풀을 생성
- **매개변수**:
  - `config`: Object (데이터베이스 설정)
- **반환값**: Connection Pool
- **처리 흐름**:
  1. mysql2/promise로 풀 생성
  2. 풀 반환

**예시 코드**:
```javascript
const mysql = require('mysql2/promise');
require('dotenv').config();

const pool = mysql.createPool({
  host: process.env.DB_L_HOST,
  user: process.env.DB_L_USER,
  password: process.env.DB_L_PASSWORD,
  database: process.env.DB_L_NAME,
  waitForConnections: true,
  connectionLimit: 10,
  queueLimit: 0
});

module.exports = pool;
```

**2. `pool.query(sql, params)`**

- **설명**: SQL 쿼리를 실행
- **매개변수**:
  - `sql`: String (SQL 쿼리문)
  - `params`: Array (파라미터 배열, 선택사항)
- **반환값**: Promise<[rows, fields]>
- **처리 흐름**:
  1. 연결 풀에서 연결 획득
  2. 쿼리 실행
  3. 결과 반환
  4. 연결 반환

### 6.4 인증 모듈 주요 데이터 구조

#### 6.4.1 JWT Payload

```javascript
{
  user_id: 1,              // 사용자 ID (users.id)
  username: "홍길동",       // 사용자 닉네임
  iat: 1701234567,         // 발급 시간 (Unix timestamp)
  exp: 1701238167          // 만료 시간 (Unix timestamp, 1시간 후)
}
```

#### 6.4.2 Kakao Token Response

```javascript
{
  access_token: "xxxxxxxxxxxxxxxxxxxxx",
  token_type: "bearer",
  refresh_token: "yyyyyyyyyyyyyyyyyyy",
  expires_in: 21599,       // 초 단위 (약 6시간)
  scope: "talk_message profile_nickname",
  refresh_token_expires_in: 5183999  // 약 60일
}
```

#### 6.4.3 Kakao User Info Response

```javascript
{
  id: 1234567890,          // Kakao 사용자 ID
  properties: {
    nickname: "홍길동"      // 사용자 닉네임
  },
  kakao_account: {
    profile: {
      nickname: "홍길동"
    }
  }
}
```

### 6.5 인증 모듈 에러 코드

| 코드 | 메시지 | HTTP Status | 설명 |
|-----|--------|-------------|------|
| 3001 | 액세스 토큰이 없습니다 | 401 | Authorization 헤더 없음 |
| 3002 | 토큰이 없습니다 | 401 | JWT 토큰 없음 |
| 3003 | 토큰이 유효하지 않습니다 | 403 | JWT 검증 실패 |
| 3004 | 토큰이 만료되었습니다 | 403 | JWT 만료 |
| 3005 | Kakao 인증 실패 | 500 | Kakao API 오류 |
