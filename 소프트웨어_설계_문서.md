## 4. 소프트웨어 Top-level 구조

### 4.1 시스템 아키텍처 개요

VitaSense는 **3계층 아키텍처(Three-Tier Architecture)**를 기반으로 설계되었습니다.

```
┌─────────────────────────────────────────────────────────────┐
│                    프레젠테이션 계층                           │
│         (Web Frontend - React/Vue + HTML Test Page)          │
└────────────────────────┬────────────────────────────────────┘
                         │ HTTP/HTTPS
                         │ REST API
┌────────────────────────▼────────────────────────────────────┐
│                    애플리케이션 계층                           │
│                  (Node.js + Express.js)                      │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐      │
│  │ 인증 모듈     │  │ PDF 분석     │  │ 알람 스케줄러 │      │
│  │ (Kakao OAuth)│  │ 모듈         │  │ (node-cron)  │      │
│  └──────────────┘  └──────────────┘  └──────────────┘      │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐      │
│  │ 영양제 추천   │  │ 건강 기록    │  │ 알림 서비스   │      │
│  │ 서비스       │  │ 관리         │  │ (KakaoTalk)  │      │
│  └──────────────┘  └──────────────┘  └──────────────┘      │
└────────────────────────┬────────────────────────────────────┘
                         │ SQL
                         │ MySQL Protocol
┌────────────────────────▼────────────────────────────────────┐
│                      데이터 계층                              │
│  ┌──────────────────────┐  ┌──────────────────────┐         │
│  │ user_info Database   │  │ vitasense Database   │         │
│  │ (사용자 인증 정보)      │  │ (영양제, 알람 정보)    │         │
│  └──────────────────────┘  └──────────────────────┘         │
│                    MySQL 8.0 (RDS)                           │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                    외부 서비스 연동                            │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐      │
│  │ Kakao OAuth  │  │ KakaoTalk    │  │ Python PDF   │      │
│  │ 2.0 API      │  │ Message API  │  │ Extractor    │      │
│  └──────────────┘  └──────────────┘  └──────────────┘      │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 주요 구성 요소

#### 4.2.1 백엔드 서버 (Node.js + Express.js)
- **역할**: 모든 비즈니스 로직 처리 및 API 제공
- **기술 스택**: Node.js 18.x, Express.js 4.x
- **포트**: 4000 (기본값)

#### 4.2.2 데이터베이스 (MySQL 8.0)
- **구조**: 이중 데이터베이스 아키텍처
  - `user_info`: 사용자 인증 및 건강 기록
  - `vitasense`: 영양제, 알람, 추천 정보
- **연결**: Connection Pool 방식

#### 4.2.3 Python PDF 분석 엔진
- **역할**: PDF 문서에서 건강 지표 추출
- **기술**: PyMuPDF, EasyOCR
- **통신**: Node.js에서 child_process로 실행

#### 4.2.4 외부 API 연동
- **Kakao OAuth 2.0**: 사용자 인증
- **KakaoTalk Messaging API**: 알림 전송

### 4.4 데이터 흐름도

#### 4.4.1 사용자 인증 흐름

```
사용자 → GET / → Kakao Login URL 반환
         ↓
사용자 → Kakao 로그인 페이지
         ↓
Kakao → Redirect with code → /kakao/callback
         ↓
authController → Kakao Token Exchange
         ↓
authController → DB에 사용자 정보 저장 (user_info.users)
         ↓
authController → JWT 토큰 발급 → httpOnly Cookie 설정
         ↓
사용자 → 로그인 완료
```

#### 4.4.2 PDF 분석 흐름

```
사용자 → POST /pdf/upload (PDF 파일)
         ↓
pdfIO.getResults → Python getResults.py 실행
         ↓
PDF_TEXT.py 또는 PDF_ocr.py → 건강 지표 추출
         ↓
pdfIO → Node.js에 JSON 반환
         ↓
pdfIO.getJudges → Python getJudge.py 실행
         ↓
건강 상태 판정 (정상/주의/위험)
         ↓
supplementService → 건강 상태 기반 영양제 추천
         ↓
사용자 → 분석 결과 + 추천 영양제 반환
```

#### 4.4.3 알람 흐름

```
사용자 → POST /alarms/setup (영양제 선택)
         ↓
alarmScheduler.setupUserAlarms
         ↓
DB에 user_choices 생성 (vitasense.user_choices)
         ↓
alarmScheduler.generateAlarmTimes
         ↓
식전/식후/상관없음 기반 시간 계산
         ↓
DB에 user_alarms 생성 (vitasense.user_alarms)
         ↓
매일 00:00 (Cron) → 새로운 알람 생성
         ↓
매분 (Cron) → 현재 시간 알람 확인
         ↓
notificationService.sendKakaoTalk
         ↓
KakaoTalk API → 사용자에게 알림 전송
```

### 6.2 각 Class들의 설계

#### 6.2.1 AuthController (authController.js)

**역할**: 인증 관련 HTTP 요청을 처리하는 컨트롤러

##### 멤버 Data 설명

| 변수명 | 타입 | 설명 |
|-------|------|------|
| `db` | Connection Pool | user_info 데이터베이스 연결 풀 |
| `jwt` | Library | JSON Web Token 라이브러리 |
| `kakaoAuthService` | Module | Kakao 인증 서비스 모듈 |
| `JWT_SECRET` | String | JWT 토큰 암호화 비밀 키 (환경변수) |
| `CLIENT_URL` | String | 프론트엔드 URL (환경변수) |

##### 멤버 함수 설명

**1. `kakaoCallback(req, res)`**

- **설명**: Kakao OAuth 콜백을 처리하여 사용자를 인증하고 JWT 토큰을 발급
- **매개변수**:
  - `req`: Express Request 객체 (code 포함)
  - `res`: Express Response 객체
- **반환값**: HTTP Response (Redirect 또는 JSON)
- **처리 흐름**:
  1. URL에서 `code` 파라미터 추출
  2. `kakaoAuthService.getKakaoToken(code)`로 액세스 토큰 받기
  3. `kakaoAuthService.getKakaoUserInfo(accessToken)`로 사용자 정보 받기
  4. 데이터베이스에서 사용자 조회 (`SELECT * FROM users WHERE kakao_id = ?`)
  5. 없으면 새 사용자 생성 (`INSERT INTO users`)
  6. JWT 토큰 발급 (`jwt.sign()`)
  7. httpOnly 쿠키에 토큰 저장
  8. 프론트엔드로 리다이렉트 (`CLIENT_URL/home`)

**예시 코드**:
```javascript
exports.kakaoCallback = async (req, res) => {
  try {
    const { code } = req.query;

    // 1. Kakao 액세스 토큰 받기
    const tokenData = await kakaoAuthService.getKakaoToken(code);
    const { access_token, refresh_token } = tokenData;

    // 2. Kakao 사용자 정보 받기
    const userInfo = await kakaoAuthService.getKakaoUserInfo(access_token);
    const { id: kakaoId, properties } = userInfo;

    // 3. DB에서 사용자 조회
    const [users] = await db.query(
      'SELECT * FROM users WHERE kakao_id = ?',
      [kakaoId]
    );

    let userId;
    if (users.length === 0) {
      // 4. 새 사용자 생성
      const [result] = await db.query(
        `INSERT INTO users (kakao_id, nickname, kakao_access_token, kakao_refresh_token)
         VALUES (?, ?, ?, ?)`,
        [kakaoId, properties.nickname, access_token, refresh_token]
      );
      userId = result.insertId;
    } else {
      userId = users[0].id;
      // 토큰 업데이트
      await db.query(
        `UPDATE users SET kakao_access_token = ?, kakao_refresh_token = ?
         WHERE id = ?`,
        [access_token, refresh_token, userId]
      );
    }

    // 5. JWT 토큰 발급
    const token = jwt.sign(
      { user_id: userId, username: properties.nickname },
      process.env.JWT_SECRET,
      { expiresIn: '1h' }
    );

    // 6. 쿠키에 토큰 저장
    res.cookie('token', token, {
      httpOnly: true,
      secure: process.env.NODE_ENV === 'production',
      maxAge: 3600000 // 1시간
    });

    // 7. 프론트엔드로 리다이렉트
    res.redirect(`${process.env.CLIENT_URL}/home`);

  } catch (error) {
    console.error('카카오 로그인 처리 중 에러 발생 :', error);
    res.status(500).json({ message: '로그인 처리에 실패했습니다.' });
  }
};
```

#### 6.2.2 AuthMiddleware (authMiddleware.js)

**역할**: 요청에서 JWT 토큰을 검증하여 인증 상태를 확인

##### 멤버 Data 설명

| 변수명 | 타입 | 설명 |
|-------|------|------|
| `jwt` | Library | JSON Web Token 라이브러리 |
| `JWT_SECRET` | String | JWT 토큰 검증용 비밀 키 (환경변수) |
| `ERROR_CODES` | Object | 에러 코드 정의 (errors.js) |

##### 멤버 함수 설명

**1. `authenticateToken(req, res, next)`**

- **설명**: JWT 토큰을 검증하여 사용자 인증 상태를 확인하는 미들웨어
- **매개변수**:
  - `req`: Express Request 객체
  - `res`: Express Response 객체
  - `next`: 다음 미들웨어로 전달하는 함수
- **반환값**: 없음 (next() 호출 또는 에러 응답)
- **처리 흐름**:
  1. 쿠키 또는 Authorization 헤더에서 토큰 추출
  2. 토큰이 없으면 에러 응답 (401)
  3. `jwt.verify()`로 토큰 검증
  4. 검증 성공 시 `req.user`에 사용자 정보 저장
  5. `next()` 호출하여 다음 미들웨어로 전달

**예시 코드**:
```javascript
const jwt = require('jsonwebtoken');
const ERROR_CODES = require('../errors');

exports.authenticateToken = (req, res, next) => {
  // 1. 쿠키 또는 헤더에서 토큰 추출
  const token = req.cookies.token ||
                (req.headers.authorization &&
                 req.headers.authorization.split(' ')[1]);

  // 2. 토큰이 없으면 에러
  if (!token) {
    return res.status(401).json({
      code: ERROR_CODES.TOKEN_MISSING,
      message: '토큰이 없습니다.'
    });
  }

  // 3. 토큰 검증
  jwt.verify(token, process.env.JWT_SECRET, (err, user) => {
    if (err) {
      // 토큰 만료 또는 유효하지 않음
      return res.status(403).json({
        code: ERROR_CODES.TOKEN_INVALID,
        message: '토큰이 유효하지 않습니다.'
      });
    }

    // 4. 사용자 정보 저장
    req.user = user;  // { user_id, username }

    // 5. 다음 미들웨어로 전달
    next();
  });
};
```

#### 6.2.3 KakaoAuthService (kakaoAuthService.js)

**역할**: Kakao API와 통신하여 OAuth 인증 처리

##### 멤버 Data 설명

| 변수명 | 타입 | 설명 |
|-------|------|------|
| `axios` | Library | HTTP 클라이언트 라이브러리 |
| `KAKAO_REST_API_KEY` | String | Kakao REST API 키 (환경변수) |
| `KAKAO_REDIRECT_URI` | String | Kakao 리다이렉트 URI (환경변수) |
| `KAKAO_CLIENT_SECRET` | String | Kakao Client Secret (환경변수) |
| `KAKAO_AUTH_URL` | String | Kakao 인증 서버 URL |
| `KAKAO_API_URL` | String | Kakao API 서버 URL |

##### 멤버 함수 설명

**1. `getKakaoLoginURL()`**

- **설명**: Kakao 로그인 URL을 생성하여 반환
- **매개변수**: 없음
- **반환값**: String (Kakao 로그인 URL)
- **처리 흐름**:
  1. Kakao OAuth 파라미터 생성 (response_type, client_id, redirect_uri, scope)
  2. URL 조합하여 반환

**예시 코드**:
```javascript
exports.getKakaoLoginURL = () => {
  const params = new URLSearchParams({
    response_type: 'code',
    client_id: process.env.KAKAO_REST_API_KEY,
    redirect_uri: process.env.KAKAO_REDIRECT_URI,
    scope: 'talk_message,profile_nickname'
  });

  return `https://kauth.kakao.com/oauth/authorize?${params.toString()}`;
};
```

**2. `getKakaoToken(code)`**

- **설명**: Authorization code를 사용하여 Kakao 액세스 토큰을 받음
- **매개변수**:
  - `code`: String (Kakao로부터 받은 authorization code)
- **반환값**: Object `{ access_token, refresh_token, expires_in }`
- **처리 흐름**:
  1. Kakao 토큰 엔드포인트에 POST 요청
  2. 응답에서 액세스 토큰 및 리프레시 토큰 추출
  3. 반환

**예시 코드**:
```javascript
exports.getKakaoToken = async (code) => {
  const params = new URLSearchParams({
    grant_type: 'authorization_code',
    client_id: process.env.KAKAO_REST_API_KEY,
    redirect_uri: process.env.KAKAO_REDIRECT_URI,
    code: code,
    client_secret: process.env.KAKAO_CLIENT_SECRET
  });

  const response = await axios.post(
    'https://kauth.kakao.com/oauth/token',
    params.toString(),
    {
      headers: {
        'Content-Type': 'application/x-www-form-urlencoded'
      }
    }
  );

  return response.data;  // { access_token, refresh_token, ... }
};
```

**3. `getKakaoUserInfo(accessToken)`**

- **설명**: 액세스 토큰을 사용하여 Kakao 사용자 정보를 조회
- **매개변수**:
  - `accessToken`: String (Kakao 액세스 토큰)
- **반환값**: Object `{ id, properties: { nickname } }`
- **처리 흐름**:
  1. Kakao API에 GET 요청 (Authorization 헤더 포함)
  2. 사용자 정보 반환

**예시 코드**:
```javascript
exports.getKakaoUserInfo = async (accessToken) => {
  const response = await axios.get('https://kapi.kakao.com/v2/user/me', {
    headers: {
      Authorization: `Bearer ${accessToken}`
    }
  });

  return response.data;  // { id, properties: { nickname }, ... }
};
```

```javascript
const { spawn } = require('child_process');

exports.getResults = (pdfBuffer, gender) => {

    pythonProcess.stdout.on('data', (data) => {
      dataString += data.toString();
    });

    // 에러 처리
    pythonProcess.stderr.on('data', (data) => {
      console.error(`Python 에러: ${data}`);
    });

    // 프로세스 종료 처리
    pythonProcess.on('close', (code) => {
      if (code !== 0) {
        reject(new Error(`Python 프로세스 종료 코드: ${code}`));
      } else {
        try {
          const result = JSON.parse(dataString);
          resolve(result);
        } catch (error) {
          reject(new Error('JSON 파싱 실패: ' + error.message));
        }
      }
    });

    // PDF 버퍼를 stdin으로 전송
```

#### 7.2.2 getResults.py

**역할**: PDF에서 건강 지표를 추출하는 Python 메인 스크립트

##### 멤버 Data 설명

| 변수명 | 타입 | 설명 |
|-------|------|------|
| `fitz` | Library | PyMuPDF 라이브러리 |
| `sys` | Library | 시스템 입출력 |
| `json` | Library | JSON 처리 |
| `PDF_TEXT` | Module | 텍스트 기반 추출 모듈 |
| `PDF_ocr` | Module | OCR 기반 추출 모듈 |

##### 멤버 함수 설명

**1. `extract_from_pdf(pdf_data, gender)`**

- **설명**: PDF 데이터에서 건강 지표 추출 (텍스트 우선, 실패 시 OCR)
- **매개변수**:
  - `pdf_data`: bytes (PDF 바이너리 데이터)
  - `gender`: str ("남" 또는 "여")
- **반환값**: dict (건강 지표 딕셔너리)
- **처리 흐름**:
  1. PyMuPDF로 PDF 열기
  2. PDF_TEXT.extract() 시도 (텍스트 기반)
  3. 실패 시 PDF_ocr.extract() 시도 (OCR 기반)
  4. 추출된 데이터 정규화
  5. JSON으로 변환하여 반환

**예시 코드**:
```python
import fitz  # PyMuPDF
import sys
import json
import PDF_TEXT
import PDF_ocr

def extract_from_pdf(pdf_data, gender):
    """PDF에서 건강 지표 추출"""
    try:
        # PDF 열기
        doc = fitz.open(stream=pdf_data, filetype="pdf")

        # 먼저 텍스트 기반 추출 시도
        try:
            results = PDF_TEXT.extract(doc, gender)
            if results and len(results) > 0:
                return results
        except Exception as e:
            print(f"텍스트 추출 실패: {e}", file=sys.stderr)

        # 텍스트 추출 실패 시 OCR 시도
        try:
            results = PDF_ocr.extract(doc, gender)
            return results
        except Exception as e:
            print(f"OCR 추출 실패: {e}", file=sys.stderr)
            return {}

    except Exception as e:
        print(f"PDF 처리 실패: {e}", file=sys.stderr)
        return {}

if __name__ == "__main__":
    # gender 인자 받기
    gender = sys.argv[1] if len(sys.argv) > 1 else "남"

    # stdin에서 PDF 데이터 읽기
    pdf_data = sys.stdin.buffer.read()
```

#### 7.2.3 getJudge.py

**역할**: 건강 지표를 판정하여 정상/주의/위험 분류

##### 멤버 Data 설명

| 변수명 | 타입 | 설명 |
|-------|------|------|
| `NORMAL_RANGES` | dict | 각 지표별 정상 범위 |
| `WARNING_RANGES` | dict | 각 지표별 주의 범위 |

##### 멤버 함수 설명

**1. `judge_health_indicator(indicator_name, value, gender)`**

- **설명**: 개별 건강 지표 판정
- **매개변수**:
  - `indicator_name`: str (지표 이름, 예: "체질량지수")
  - `value`: float (측정값)
  - `gender`: str ("남" 또는 "여")
- **반환값**: str ("정상" | "주의" | "위험")
- **처리 흐름**:
  1. 지표별 정상 범위 확인
  2. 성별 고려 (일부 지표는 성별로 다른 기준)
  3. 값 비교하여 판정 반환

**예시 코드**:
```python
import sys
import json

# 정상 범위 정의
NORMAL_RANGES = {
    "체질량지수": {"min": 18.5, "max": 24.9},
    "고혈압_수축기": {"min": 90, "max": 119},
    "고혈압_이완기": {"min": 60, "max": 79},
    "공복혈당": {"min": 70, "max": 99},
    "간기능_AST": {"min": 0, "max": 40},
    "간기능_ALT": {"min": 0, "max": 40},
    "신장기능_크레아티닌": {"min": 0.7, "max": 1.3},
    "빈혈_혈색소": {
        "남": {"min": 13.0, "max": 17.0},
        "여": {"min": 12.0, "max": 16.0}
    }
}

def judge_health_indicator(indicator_name, value, gender="남"):
    """개별 건강 지표 판정"""
    if indicator_name not in NORMAL_RANGES:
        return "알 수 없음"

    ranges = NORMAL_RANGES[indicator_name]

    # 성별 구분이 있는 경우
    if isinstance(ranges, dict) and gender in ranges:
        ranges = ranges[gender]

    # 값이 없는 경우
    if value is None or value == "":
        return "측정 안 됨"

    try:
        value = float(value)
    except:
        return "측정 안 됨"

    # 정상 범위 확인
    if ranges["min"] <= value <= ranges["max"]:
        return "정상"

    # 주의 범위 (정상 범위에서 10% 벗어남)
    warning_margin = (ranges["max"] - ranges["min"]) * 0.1
    if (ranges["min"] - warning_margin) <= value <= (ranges["max"] + warning_margin):
        return "주의"

    # 위험
    return "위험"

def judge_all(health_data):
    """모든 건강 지표 판정"""
    gender = health_data.get("gender", "남")
    judgments = {}

    for indicator_name, value in health_data.items():
        if indicator_name == "gender":
            continue
        judgments[f"{indicator_name}_판정"] = judge_health_indicator(indicator_name, value, gender)

    return judgments

if __name__ == "__main__":
    # stdin에서 건강 데이터 JSON 읽기
    health_data = json.load(sys.stdin)

    # 판정 수행
    judgments = judge_all(health_data)

    # JSON으로 출력
    print(json.dumps(judgments, ensure_ascii=False))
```

### 8.2 각 Class들의 설계

#### 8.2.1 AlarmScheduler (alarmScheduler.js)

**역할**: 사용자별 알람 생성 및 관리, 시간 계산

##### 멤버 Data 설명

| 변수명 | 타입 | 설명 |
|-------|------|------|
| `db` | Connection Pool | vitasense 데이터베이스 연결 |
| `MEAL_TIMES` | Object | 기본 식사 시간 (아침, 점심, 저녁) |
| `MEAL_OFFSET` | Object | 식전/식후 시간 오프셋 (분 단위) |

##### 멤버 함수 설명

**1. `parseMealTiming(howToUseText)`**

- **설명**: 영양제 복용법 텍스트에서 식전/식후 정보 추출
- **매개변수**:
  - `howToUseText`: String (영양제 복용법 텍스트)
- **반환값**: String ("식전" | "식후" | "상관없음")
- **처리 흐름**:
  1. 텍스트에서 "식전", "식후" 키워드 검색
  2. 매칭되는 키워드 반환
  3. 없으면 "상관없음" 반환

**예시 코드**:
```javascript
const db = require('../db');

// 기본 식사 시간 (KST)
const MEAL_TIMES = {
  breakfast: '07:00',
  lunch: '12:00',
  dinner: '19:00'
};

// 식전/식후 오프셋 (분)
const MEAL_OFFSET = {
  before: -30,  // 식전: 30분 전
  after: 30     // 식후: 30분 후
};

/**
 * 복용법 텍스트에서 식전/식후 파싱
 */
function parseMealTiming(howToUseText) {
  if (!howToUseText) return '상관없음';

  const text = howToUseText.toLowerCase();

  if (text.includes('식전')) {
    return '식전';
  } else if (text.includes('식후')) {
    return '식후';
  } else {
    return '상관없음';
  }
}

module.exports.parseMealTiming = parseMealTiming;
```

**2. `generateAlarmTimes(dailyCount, mealTiming)`**

- **설명**: 1일 복용 횟수와 식사 시간 기준으로 알람 시간 생성
- **매개변수**:
  - `dailyCount`: Number (1, 2, 또는 3)
  - `mealTiming`: String ("식전" | "식후" | "상관없음")
- **반환값**: Array<String> (시간 배열, 예: ["07:00", "12:00"])
- **처리 흐름**:
  1. dailyCount에 따라 기본 식사 시간 선택
  2. mealTiming에 따라 오프셋 적용
  3. HH:mm 형식의 시간 배열 반환

**예시 코드**:
```javascript
/**
 * 알람 시간 생성
 */
function generateAlarmTimes(dailyCount, mealTiming) {
  let baseTimes = [];

  // dailyCount에 따라 기본 시간 선택
  switch (dailyCount) {
    case 1:
      baseTimes = [MEAL_TIMES.breakfast];
      break;
    case 2:
      baseTimes = [MEAL_TIMES.breakfast, MEAL_TIMES.lunch];
      break;
    case 3:
      baseTimes = [MEAL_TIMES.breakfast, MEAL_TIMES.lunch, MEAL_TIMES.dinner];
      break;
    default:
      baseTimes = [MEAL_TIMES.breakfast];
  }

  // 식전/식후 오프셋 적용
  let offset = 0;
  if (mealTiming === '식전') {
    offset = MEAL_OFFSET.before;
  } else if (mealTiming === '식후') {
    offset = MEAL_OFFSET.after;
  }

  // 시간 계산
  const alarmTimes = baseTimes.map(timeStr => {
    const [hours, minutes] = timeStr.split(':').map(Number);
    const totalMinutes = hours * 60 + minutes + offset;

    const newHours = Math.floor(totalMinutes / 60);
    const newMinutes = totalMinutes % 60;

    return `${String(newHours).padStart(2, '0')}:${String(newMinutes).padStart(2, '0')}`;
  });

  return alarmTimes;
}

module.exports.generateAlarmTimes = generateAlarmTimes;
```

**3. `setupUserAlarms(userId, conditionName, supplementId, selectedDailyCount)`**

- **설명**: 사용자 알람 설정 생성 및 초기 알람 생성
- **매개변수**:
  - `userId`: Number (사용자 ID)
  - `conditionName`: String (건강 상태 이름)
  - `supplementId`: Number (영양제 ID)
  - `selectedDailyCount`: Number (1일 복용 횟수)
- **반환값**: Promise<Object> (생성된 choice 정보)
- **처리 흐름**:
  1. 영양제 정보 조회 (복용법 확인)
  2. parseMealTiming()으로 식전/식후 파악
  3. user_choices 테이블에 INSERT
  4. generateAlarmTimes()로 알람 시간 계산
  5. 오늘 날짜 알람 생성 (user_alarms INSERT)

**예시 코드**:
```javascript
/**
 * 사용자 알람 설정
 */
async function setupUserAlarms(userId, conditionName, supplementId, selectedDailyCount) {
  try {
    // 1. 영양제 정보 조회
    const [supplements] = await db.query(
      'SELECT how_to_use FROM supplements WHERE id = ?',
      [supplementId]
    );

    if (supplements.length === 0) {
      throw new Error('영양제를 찾을 수 없습니다.');
    }

    const howToUse = supplements[0].how_to_use;

    // 2. 식전/식후 파악
    const mealTiming = parseMealTiming(howToUse);

    // 3. user_choices 생성 (UNIQUE 제약으로 중복 방지)
    const [result] = await db.query(
      `INSERT INTO user_choices (user_id, condition_name, supplement_id, daily_count, meal_type)
       VALUES (?, ?, ?, ?, ?)
       ON DUPLICATE KEY UPDATE supplement_id = ?, daily_count = ?, meal_type = ?`,
      [userId, conditionName, supplementId, selectedDailyCount, mealTiming,
       supplementId, selectedDailyCount, mealTiming]
    );

    const choiceId = result.insertId || (await db.query(
      'SELECT choice_id FROM user_choices WHERE user_id = ? AND condition_name = ?',
      [userId, conditionName]
    ))[0][0].choice_id;

    // 4. 알람 시간 생성
    const alarmTimes = generateAlarmTimes(selectedDailyCount, mealTiming);

    // 5. 오늘 날짜 알람 생성
    const today = new Date().toISOString().split('T')[0]; // YYYY-MM-DD

    for (const alarmTime of alarmTimes) {
      await db.query(
        `INSERT IGNORE INTO user_alarms (choice_id, alarm_date, alarm_time, meal_type, intake_status)
         VALUES (?, ?, ?, ?, ?)`,
        [choiceId, today, alarmTime, mealTiming, '미확인']
      );
    }

    return {
      choiceId,
      dailyCount: selectedDailyCount,
      mealTiming,
      alarmTimes
    };

  } catch (error) {
    console.error('알람 설정 오류:', error);
    throw error;
  }
}

module.exports.setupUserAlarms = setupUserAlarms;
```

  - `choiceId`: Number (user_choices ID)
  - `date`: String (YYYY-MM-DD 형식)

**예시 코드**:
```javascript
/**
 * 일일 알람 생성 (Cron에서 호출)
 */
async function createDailyAlarms(choiceId, date) {
```

**5. `getTodayAlarms(userId)`**

- **설명**: 특정 사용자의 오늘 알람 목록 조회
- **매개변수**:
  - `userId`: Number (사용자 ID)
- **반환값**: Promise<Array> (알람 목록)
- **처리 흐름**:
  1. 오늘 날짜 구하기
  2. user_alarms JOIN user_choices JOIN supplements
  3. userId로 필터링
  4. alarm_time 순서로 정렬

**예시 코드**:
```javascript
/**
 * 오늘의 알람 조회
 */
async function getTodayAlarms(userId) {
  const today = new Date().toISOString().split('T')[0];

  const [alarms] = await db.query(
    `SELECT
      ua.alarm_id,
      ua.alarm_date,
      ua.alarm_time,
      ua.meal_type,
      ua.intake_status,
      s.item_name,
      s.how_to_use,
      uc.condition_name
    FROM user_alarms ua
    JOIN user_choices uc ON ua.choice_id = uc.choice_id
    JOIN supplements s ON uc.supplement_id = s.id
    WHERE uc.user_id = ? AND ua.alarm_date = ?
    ORDER BY ua.alarm_time`,
```

**6. `recordIntakeStatus(alarmId, status)`**

- **설명**: 알람의 복용 상태 업데이트

- **반환값**: Promise<void>
- **처리 흐름**:
  1. user_alarms 테이블 UPDATE
  2. intake_status 값 변경

**예시 코드**:
```javascript
/**
 * 복용 상태 기록
 */
async function recordIntakeStatus(alarmId, status) {
  const validStatuses = ['복용', '미복용', '미확인'];

  if (!validStatuses.includes(status)) {
    throw new Error('유효하지 않은 상태값입니다.');
  }

  await db.query(
    'UPDATE user_alarms SET intake_status = ? WHERE alarm_id = ?',
    [status, alarmId]
  );

  console.log(`[Scheduler] 알람 ${alarmId} 상태 업데이트: ${status}`);
}

module.exports.recordIntakeStatus = recordIntakeStatus;
```
